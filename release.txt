This release hardens native Venus OS services, grid-loss handling and installation on constrained GX hardware.

Changes:
- Keep the shared D-Bus connection and subscriptions alive after an individual request timeout; clean up cancelled request handlers on dbus-fast 2.21.1.
- Reject stale or invalid grid telemetry, pin the selected grid source when configured, and expose a bounded configurable hold before applying zero on grid loss.
- Preserve device-local configuration and service supervisor directories during updates, validate startup with a fresh heartbeat, and keep transient state under /run.
- Include the configuration example and every updater runtime item in the PackageManager release archive.
- Bound logging and forward logs without replaying already-read lines.

The grid-loss hold remains a device-local setting. Existing values are preserved. Home Assistant continues to own scheduling, battery reserve policy and Quattro on/off transitions.

Validation: native transport regression suite and a read-only dbus-fast 2.21.1 target smoke test; isolated filesystem upgrade and release-archive tests. Meter-side Modbus UDP dropouts require separate investigation and are not claimed to be eliminated by this release.
