## v1.21.0 — TOU Expensive Window + MQTT Notifications

### Time-of-Use expensive window (solar forecast pre-charge suppression)
Pre-charge triggered by the solar-forecast webhook is **suppressed inside the configured expensive-grid window** so the battery never force-charges from expensive power.

- Window hours: `TOU_EXPENSIVE_START_HOUR` / `TOU_EXPENSIVE_END_HOUR` (default 15→24, i.e. 3 PM–midnight; `-1/-1` disables; windows may wrap midnight)
- Resolution order: **GUI settings → local_config.py → env → default**
- On Cerbo the two hours are created automatically as GUI-editable localsettings under `/Settings/InverterControl/` (`TouExpensiveStartHour`, `TouExpensiveEndHour`) — edit them from the Venus Settings menu (GX screen / VRM / GUIv2), no SSH needed
- Existing values are never overwritten on reinstall; uninstall removes the settings
- Window hour follows the user's wall clock via the GX `/Settings/System/TimeZone` setting even though the Venus system clock runs UTC

### MQTT notifications on pre-charge (#104)
- `inverter/notifications` topic publishes `{id, level, title, body, source, ts}` on every pre-charge trigger and suppression — consumed by inverter-desktop banner UI
- Webhook handler is idempotent per hour and answers 200 to the forecast service
