## v1.17.1

### Fix: Restore missing daily_stats fields in MQTT state

Dashboard showed zeros for several daily energy metrics because `daily_stats` was missing fields the frontend expects.

Added to MQTT `inverter/state` payload:
- `produced_dollars` — daily revenue from solar production
- `battery_in_yesterday` — kWh charged to battery yesterday
- `battery_out_yesterday` — kWh discharged from battery yesterday
- `pv_total_daily` — total kWh from all MPPT chargers

### Fix: publish-release workflow on protected branches

GitHub Contents API rejects direct writes to protected `main` branch. Workflow now creates a temporary branch, opens a PR, merges, and cleans up.
